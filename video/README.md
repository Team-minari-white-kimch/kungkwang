# 온보딩 사용법 영상

이 폴더에 `onboarding.mp4`를 올리면 온보딩 2단계 "영상으로 보는 사용법"에 자동으로 나옵니다. 파일이 없으면 "사용법 영상을 준비하고 있어요" 안내가 보입니다.

- 권장 형식: MP4(H.264 + AAC), 세로 9:16(예: 1080×1920), 1~2분, 10MB 안팎
- 썸네일을 쓰려면 이미지를 이 폴더에 올리고 `index.html`의 `ONB_POSTER`에 경로를 넣으세요(예: `'video/onboarding.jpg'`).
- 유튜브 영상을 쓰려면 `index.html`의 `ONB_VIDEO`에 유튜브 주소(`https://youtu.be/…`)를 넣으세요.
